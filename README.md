# IT Support Troubleshooting Guide

**Project description:** Practical troubleshooting guides for common computer and connectivity issues.

## 1. Computer Running Slowly

**Problem:** A computer takes a long time to start or open applications.

**Troubleshooting steps:**
1. Ask the user when the problem started.
2. Open Task Manager and check CPU, memory, and disk usage.
3. Check available storage space.
4. Close unnecessary applications if appropriate.
5. Restart the computer if safe to do so.
6. Check whether performance improves.

**Verification:** Confirm whether the computer starts and opens applications more quickly.

**Escalation:** Refer the issue to a senior technician if the problem continues or hardware failure is suspected.

## 2. Unable to Connect to Wi-Fi

**Problem:** A computer cannot access the internet through Wi-Fi.

**Troubleshooting steps:**
1. Confirm that Wi-Fi is enabled.
2. Check whether other devices can connect.
3. Verify that the correct wireless network is selected.
4. Disconnect and reconnect to the network.
5. Run `ipconfig` to inspect network settings.
6. Restart networking equipment only when authorised.

**Verification:** Open a website to check whether internet access has returned.

**Escalation:** Escalate if several devices are affected or the problem requires administrator assistance.

## 3. Application Not Responding

**Problem:** An application freezes or stops responding.

**Troubleshooting steps:**
1. Record the application name and any error message.
2. Wait briefly to see whether it recovers.
3. Close and reopen the application if safe.
4. Check for application updates.
5. Restart the computer if appropriate.
6. Record the steps taken and the outcome.

**Verification:** Confirm that the application opens and functions normally.

**Escalation:** Escalate if the problem persists or important unsaved work is at risk.

## Standard Troubleshooting Process
1. Identify the issue.
2. Gather information from the user.
3. Investigate possible causes.
4. Apply an appropriate solution.
5. Verify that the issue is resolved.
6. Document the outcome.
7. Escalate unresolved issues.
